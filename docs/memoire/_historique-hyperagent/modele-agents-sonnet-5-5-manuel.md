# Modèle des agents : Claude Sonnet 5.5, mode Manuel (propre à Hyperagent)

> **Non applicable à Antigravity** — mémoire propre à Hyperagent, conservée pour historique uniquement. Ne pas appliquer ces règles.

## Contenu intégral (inchangé)

Projet Fisca : tous les agents de l'usine logicielle tournent sur Claude Sonnet 5.5, en mode modèle Manuel. Ne pas proposer GLM 5.3 ni les profils Auto « Low cost », dont GLM fait partie. L'utilisateur veut réduire les coûts, mais un modèle moins cher (par exemple Haiku 5.5 pour le curateur ou les sous-agents) ne doit être adopté qu'après un test de qualification dans le projet.
