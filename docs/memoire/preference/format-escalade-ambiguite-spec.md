# Format d'escalade d'une ambiguïté de spécification (section 04)

## Contenu intégral (inchangé)

When escalating a Fisca spec ambiguity to the pilot, write in FISCA_STATE_AND_HANDOFF section 04: (1) the precise question, and (2) the two possible readings, each with its exact spec citation. Keep the current implementation and mark it as provisional. The pilot does not decide spec contradictions alone; they go to the owner. Questions phrased vaguely are sent back as 'mal posée'.
