# Matrice sessions → documents de spécification à lire (3 à 5 par session)

## Contenu intégral (inchangé)

Projet Fisca : les 18 documents de spécification (Doc 01–18) ne sont jamais injectés tous ensemble dans une session de construction. Chaque session lit, dans docs/specs/ de son clone, seulement les 3 à 5 documents de sa ligne dans la matrice des sessions (référentiel v2 du 2026-11-13, skill fisca-factory-runbook), plus ERRATA.md : S0 = 01, 04, 05, 14, 15 ; S1A = 09, 10, 11, 15 ; S1B = 02, 04, 06, 07, 15 ; G1 = 06, 09, 10, 14 ; P2-A = 02, 05, 07, 10, 17 ; P2-B = 01, 02, 07, 08 ; P2-C = 03, 08, 11, 18 ; G2 = 02, 08, 14, 18 ; P3-A = 02, 06, 07, 14 ; P3-B = 04, 07, 10, 13 ; P3-C = 05, 07, 14, 17 ; G3 = 07, 13, 14, 17 ; P4-A = 01, 08, 09 ; P4-B = 02, 03, 12, 13, 17 ; P4-C = 04, 11, 12, 16 ; G4 = 03, 09, 12, 14 ; S5 = 11, 12, 14, 16. Cette matrice remplace l'ancien aperçu (S0 = 01, 04, 06, 14, 15 ; Backend = 02, 04, 06, 10 ; Frontend = 01, 02, 08).
