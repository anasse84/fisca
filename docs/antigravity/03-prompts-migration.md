# 03 — Prompts à passer à Antigravity pour qu'il adapte lui-même l'environnement

Mode d'emploi : ouvre `agy` à la racine du dépôt (`cd ~/fisca-factory/fisca && agy`), choisis le modèle le plus fort (`/model`), puis colle **un prompt à la fois**, dans l'ordre. Passe au suivant seulement quand le précédent se termine par « M<n> TERMINÉ ». Chaque prompt crée une branche `fix/…` et une Pull Request ; tu valides la PR (ou laisses M8 la fusionner). Les prompts sont autosuffisants.

Règles communes (déjà dans `AGENTS.md`, rappelées par prudence) : aucune invention (« NON RECOUPÉ » si une information manque), aucun secret écrit dans un fichier, jamais de push direct sur `main`, jamais de force-push, répondre en français.

---
## M0 — Prise de connaissance et inventaire
```text
Tu reprends l'usine logicielle Fisca (SaaS marocain de facturation électronique, dépôt anasse84/fisca) qui tournait sur la plateforme Hyperagent et passe sur Antigravity CLI. Ne modifie rien dans ce tour.
1. Lis AGENTS.md, docs/antigravity/00-LISEZ-MOI.md et 02-correspondance-hyperagent-antigravity.md, docs/state/FISCA_STATE_AND_HANDOFF.md (section 01), docs/specs/ERRATA.md (en-tête et sections B, D, F), docs/orchestration/pilotage-automatique.md et protocole-boucle.md.
2. Exécute `agy --version`, `agy models`, `agy agents`, `agy mcp list` et note ce qui est disponible (agents, modèles, effort).
3. Dresse l'inventaire dans docs/antigravity/inventaire-M0.md : (a) fichiers de .agents/ présents et conformes ou non (frontmatter name/description pour les skills ; name, description, subagent: true, tools, model pour les agents) ; (b) références résiduelles à Hyperagent (cherche : Hyperagent, GetTable, ScheduleWakeUp, CreateAgentThread, RunWithCredentials, FetchSkillScripts, RequestNetworkAccess, SuggestFollowUps, fil, voie dans docs/ et .agents/) avec chemin et ligne ; (c) taille de AGENTS.md en jetons estimés (budget 20 000 avec les règles globales) ; (d) incohérences entre documents.
Termine par « M0 TERMINÉ » et le nombre d'éléments à corriger.
```

